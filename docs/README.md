# RAG System Evaluation Reports

This directory contains auto-generated HTML evaluation reports.

## 📊 View Report

- **Local**: Open `index.html` in your browser
- **GitHub Pages**: Visit `https://<your-username>.github.io/rag-bootcamp/`

## 🔄 Report Updates

Reports are automatically generated and updated by GitHub Actions when:
- New documents are added to `iteration7/corpus/`
- Evaluation code is modified
- Manually triggered via Actions workflow

## 🚀 Setup GitHub Pages

1. Go to repository **Settings** → **Pages**
2. Under "Source", select:
   - **Deploy from a branch**
   - Branch: `main`
   - Folder: `/reports`
3. Click **Save**
4. Wait 1-2 minutes for deployment
5. Access your report at the GitHub Pages URL shown

## ⚠️ Note

The `index.html` file will be created after the first evaluation run. If you see a 404 error:
1. Ensure you've run the evaluation at least once
2. Check that `index.html` exists in this directory
3. Wait a few minutes for GitHub Pages to update
