```
检测到设备电流在短时间内下降至接近零，判定设备充满电，自动关闭插座，防止过充。
```

### Rerank 分数
```

[5] Score: 0.0628
```

### 生成的答案
```
未找到充分依据。提供的资料片段中未提及 SmartPlug-400 的充电保护功能。
仅有关于电流测量精度、过载保护、定时开关等描述，但未涉及充电保护的工作原理。
```

### 问题分析

**1. 答案位置问题**
- 答案在 doc-6.txt 中间部分："检测到设备电流在短时间内下降至接近零..."
- 这是一个完整的句子，长度约 35 个字
- 使用 `fixed_200_40` 分块策略（200字/块，40字重叠）

**2. 可能的原因**

**原因A：答案被切分到块边界**
- 如果答案恰好在块的边界位置
- 前一块和后一块都只包含部分信息
- 导致单独的块都不足以回答问题

**原因B：答案被其他内容"稀释"**
- doc-6.txt 很长，包含很多其他功能描述
- 200字的块可能包含：
  - 前面：电量统计、定时开关、过载保护
  - 中间：充电保护功能（目标答案）
  - 后面：分享功能、固件升级
- 关键信息密度低，被其他信息掩盖

**原因C：关键词不匹配**
- 查询："充电保护功能是怎样工作的"
- 文档："检测到设备电流在短时间内下降至接近零，判定设备充满电，自动关闭插座，防止过充"
- 文档中没有"充电保护"这个词，用的是"防止过充"
- Vector Search 和 BM25 可能都没有很好地匹配

**原因D：Reranker top-1 分数很高（0.9754）但仍然不对**
- 说明检索到的块虽然相关性高，但不包含答案
- 可能检索到的是其他 SmartPlug-400 的功能描述

### 改进建议

1. **多粒度检索**
   - 同时使用 small_100_50 和 fixed_200_40
   - small_100_50 可能更精确地切到这个句子

2. **关键词扩展**
   - "充电保护" → "防止过充"、"充满电自动断电"
   - Query rewriting 或 query expansion

3. **增加召回候选数**
   - 当前召回 top-20
   - 可以尝试 top-30 或 top-40

## 【案例 2】传感器没电了怎么换？

### 查询信息
- **Query ID**: 27
- **Query**: "传感器没电了怎么换？"
- **Category**: semantic_paraphrase
- **正确答案来源**: doc-5.txt

### 正确答案文本（在 doc-5.txt 中）
```
传感器 ST-500 采用红外热释电传感器...
使用 CR123A 锂电池，续航约 2 年（取决于触发频率）。
```

### Rerank 分数
```
[1] Score: 0.8359
[2] Score: 0.8332
[3] Score: 0.3703
[4] Score: 0.3730
[5] Score: 0.2746
```

### 生成的答案
```
根据资料，传感器电池更换如下：ST-500/ST-501使用CR2032纽扣电池，正常使用12-18个月；
ST-600是锂电池可充电，续航约12个月。低电量时APP会提前30天提醒，别等到彻底没电才换。
[文档14:片段1] 关于具体的更换步骤，资料中未提供详细操作指导。
```

### 问题分析

**1. 答案确实在 doc-5.txt 中**
```
使用 CR123A 锂电池，续航约 2 年（取决于触发频率）。
```

**但生成答案引用了 doc-14（FAQ）：**
```
ST-500/ST-501使用CR2032纽扣电池，正常使用12-18个月
```

**矛盾！doc-5 说 CR123A，doc-14 说 CR2032**

**2. 语义差异问题**

**查询**: "传感器没电了怎么换？"
- 关键需求：**更换步骤**（"怎么换"）
- 次要信息：电池型号、续航时间

**doc-5 内容**:
- ✅ 有电池型号（CR123A）
- ❌ **没有更换步骤**（没说怎么打开、怎么装）

**doc-14 内容（FAQ）**:
- ✅ 有电池型号（但错误：CR2032 vs CR123A）
- ✅ 有使用建议（提前30天更换）
- ❌ **仍然没有更换步骤**

**3. 根本原因：文档中确实没有更换步骤**

查询的核心是"怎么换"（操作步骤），但：
- doc-5 只提到电池型号
- doc-14 只提到更换时机
- **没有任何文档描述更换步骤**（如：打开后盖、取出旧电池、装入新电池、合上后盖）

**4. 为什么检索失败？**

**Rerank top-1 分数只有 0.8359（相对较低）**
- 说明 Reranker 已经意识到检索结果不太相关
- 但没有更好的候选

**可能检索到了 doc-14（FAQ）而不是 doc-5（官方文档）**
- doc-14 FAQ 有"电池没电"相关讨论
- 语义上更接近"怎么换"这种口语化表达
- 但信息不完整且有错误

### 改进建议

1. **文档质量问题**
   - doc-5 应该补充更换步骤
   - 或者在 doc-13（安装指南）中补充

2. **信息一致性检查**
   - doc-5 说 CR123A
   - doc-14 说 CR2032
   - 需要修正错误

3. **检索策略优化**
   - 优先检索官方文档（doc-1~7）
   - FAQ（doc-14）作为补充
   - 可以给不同来源的文档设置权重

2. **案例 2（电池更换）**:
   - 查询要"更换步骤"，但文档只有"电池型号"
